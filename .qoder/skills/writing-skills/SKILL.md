# Writing Skills Skill

## 触发条件

- 需要创建新的 Agent 技能
- 需要更新已有技能

## 行为指南

### 技能文件规范

每个技能文件必须遵循以下结构：

```markdown
# <Skill Name> Skill

## 触发条件
- 什么情况下激活此技能

## 行为指南
- Agent 应该做什么
- 具体的步骤和流程

## 输出格式（可选）
- 预期的输出格式
```

### 技能设计原则

1. **单一职责**: 每个技能只做一件事
2. **可组合**: 技能可以串联使用
3. **可验证**: 技能有明确的输出，可以判断是否正确执行
4. **工具无关**: 技能描述行为，不依赖特定 IDE/工具
5. **简洁**: 用最少的文字准确描述行为

### 技能目录结构

```
.qoder/skills/<skill-name>/
└── SKILL.md    # 技能定义文件（唯一必需文件）
```

### 测试技能

创建技能后，在 AGENTS.md 中注册，然后通过实际场景测试：
1. 触发技能条件
2. 观察 agent 行为
3. 验证输出是否符合预期
4. 必要时调整

### 好的技能示例

- ✅ brainstorming — 明确的触发条件 + 结构化的步骤 + 输出格式
- ✅ test-driven-development — 清晰的流程 + 反模式说明 + 输出格式
- ❌ "code-better" — 太模糊，不知道什么时候触发，做什么
